# Memrium: концепт

Робочий стіл для Wayland, який **виглядає як ви захочете**. Одна й та сама система показує macOS із «рідким склом», Fluent чи Aero (Aero), а також будь-що своє: вигляд, розкладка, іконки та шпалери описані даними, а не зашиті в код.

## 1. Ідея в трьох реченнях

1. Увесь інтерфейс оболонки (панелі, Dock, меню, вікна, налаштування) малює один GPU-шейдер «скла» з параметрами, які задає **тема**.
2. **Тема** — це TOML-файл: розкладка, стиль скла, вікна, іконки, шрифти, шпалери. Шаблони (macOS, Fluent, Aero) — лише вбудовані теми, їх можна змінювати чи копіювати.
3. Усе змінюється наживо з вікна **Налаштувань** (яке теж намальоване оболонкою), без перезапуску.

## 2. Шари системи

```
застосунки (Wayland-клієнти: foot, Firefox, Qt/GTK, наш memrium-term)
        │  wl_shm (dmabuf — пізніше)
композитор  ── протокол: smithay ── вікна, попапи, підвікна, фокус, ввід
        │
оболонка (shell) ── розкладка + віджети, що читають Тему
        │
рендерер wgpu ── шейдер скла: заломлення, розмиття, відблиск, тіні, текст, іконки
        │
бекенд: вкладений (winit)  |  сесія (DRM/KMS + libinput + libseat)
```

## 3. Тема (дані)

```toml
name   = "Aero"
layout = "taskbar"            # "macos" | "taskbar"
dark   = false
accent = [0.20, 0.55, 0.95]

[glass]                       # вигляд «поверхонь» оболонки
blur = 12  refraction = 6  dispersion = 0.0  rim = 0.4  gloss = 0.5
tint = [0.45, 0.62, 0.85, 0.45]
border = [1.0, 1.0, 1.0, 0.55]
shadow = [0.30, 24, 8]

[window]
decoration = "aero"           # "mac" | "win11" | "aero" | "minimal"
radius = 8  titlebar = 30  buttons = "right"  title_align = "left"

[taskbar]                     # коли layout = "taskbar"
position = "bottom"  size = 40  align = "left"  floating = false
start = "orb"                 # "orb" | "logo" | "none"
labels = false  indicator = "glass_button"   # "dot" | "underline" | "glass_button"
tray = true  clock = "two_line"

[launcher]
style = "start_menu_win7"     # "figlet" | "start_menu_win11" | "start_menu_win7"

[icons]                       # див. розділ 5
[wallpaper]                   # див. розділ 6
```

Користувач може лишити лише різницю: `theme = "windows11"` плюс кілька рядків, що перевизначають окремі поля.

## 4. Три вбудовані шаблони

| | Jelly Glass | Fluent | Aero |
|---|---|---|---|
| Розкладка | меню-бар зверху + плаваючий Dock знизу + Quick Settings | панель знизу, значки по центру, пошук, трей | панель знизу, кнопка «Пуск» (куля) ліворуч, трей |
| Скло | сильне заломлення, відблиски, дисперсія | плоске «акрилове»: розмиття без заломлення, м'які кути | глянцеве: градієнт, блик, світла рамка |
| Вікна | «світлофори» ліворуч, радіус 26 | кнопки праворуч (─ □ ✕), радіус 8 | товста скляна рамка, червона «✕» |
| Меню запуску | Figlet | меню «Пуск» (закріплені + рекомендовані) | двоколонкове «Пуск» |
| Іконки | «squircle» Apple-стилю | плоскі, без плашки | з легким глянцевим відбитком |

Шаблони «за мотивами»: власні гліфи й малюнки, без логотипів Microsoft та Apple.

## 5. Кастомізація іконок

Іконки бувають трьох видів, і кожен налаштовується окремо.

**Іконки застосунків** (Dock, панель, лаунчер, перемикач):
- **Тема іконок:** `auto` (береться з KDE/GNOME), або будь-яка тека за стандартом freedesktop (Papirus, Breeze, Adwaita, власна).
- **Форма-маска:** `none`, `squircle`, `circle`, `rounded` — єдина форма для всіх, навіть якщо тема її не має.
- **Плашка під іконкою:** немає / скляна / суцільний колір, з відступом (padding) і тінню.
- **Тонування:** моно-режим одним кольором (корисно для мінімалістичних тем) або автоматично за акцентом.
- **Перевизначення для окремих застосунків:** `[icons.overrides]  "org.kde.dolphin" = "~/icons/folder.svg"`.
- **Розмір і збільшення** у Dock/на панелі, інтервал між значками.

**Системні гліфи інтерфейсу** (меню, трей, кнопки вікон, Quick Settings): набір **Lucide** за замовчуванням. Можна підмінити набір власною текою SVG: файл `wifi.svg` перекриває однойменний гліф. Товщина лінії та колір задаються темою.

**Іконки файлів/тек** і курсор — окремі набори (етап пізніше).

## 6. Шпалери

- **Статичні:** будь-яке зображення, режими «заповнити / вписати / розтягнути / плитка».
- **Живі (шейдери):** вбудовані («Aurora», «Liquid Gradient», «Waves», «Ocean») і власні `.wgsl`-файли з однією функцією `live(uv, time) -> color`; помилка шейдера не ламає стіл — лишається попередні шпалери і показується повідомлення.
- **Відео:** потік кадрів через `ffmpeg` (якщо встановлений), з паузою, коли вікна закривають екран.
- **Динамічні за часом доби:** набір зображень, що змінюється за годинником.

## 7. Налаштування (вікно оболонки)

- **Вигляд:** шаблони-картки, світла/темна, акцент, повзунки скла (розмиття, заломлення, прозорість).
- **Шпалери:** сітка мініатюр (статичні й живі), додавання теки.
- **Розкладка:** меню-бар/панель, положення, вирівнювання, підписи, плаваюча/притиснута, віджети й їхній порядок.
- **Вікна:** стиль заголовка, радіус, тінь, анімації (пружинність).
- **Іконки:** тема, форма, плашка, тонування, перевизначення.
- **Dock/Панель:** закріплені застосунки, розмір, збільшення.
- **Про систему** та шлях до конфігів.

Усі зміни застосовуються миттєво й зберігаються в `~/.config/memrium/config.toml`.

## 8. Принципи

1. **Дані, а не код:** будь-який вигляд має бути виражений у темі.
2. **Один рендерер:** панелі, вікна, іконки, текст і шпалери проходять через спільний шейдер, тому все узгоджене і «живе» (пружини, заломлення).
3. **Безпечні збої:** погана тема чи шейдер → повернення до вбудованого шаблону й повідомлення, а не чорний екран.
4. **Працює вкладено й нативно:** розробка у вікні, справжня робота — сесією з TTY.
5. **Власні значки:** жодних чужих логотипів і чужих шрифтів у репозиторії.
